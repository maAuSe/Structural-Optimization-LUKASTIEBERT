\begin{abstract}
This report investigates the computational efficiency of the multiresolution topology optimization (MTOP) approach for a two-dimensional minimum-compliance MBB beam. The MTOP formulation uses a coarse finite element analysis mesh and a finer density mesh. Its convergence behavior, computation time, and optimized layouts are compared with a classical density-based topology optimization formulation at the same final density resolution.
\end{abstract}

\section{Problem statement}

The aim of this assignment is to assess whether the MTOP approach introduced by Nguyen et al.~\cite{nguyen2010mtop} can reduce computation time for two-dimensional minimum-compliance topology optimization without significantly changing the optimized structural layout.

The benchmark problem is the half MBB beam from the lecture code. The classical formulation is solved on a fine finite element mesh, while the MTOP formulation performs finite element analysis on a coarser mesh and represents the material distribution on a finer density mesh.

\section{Structural model}

\subsection{Geometry and discretization}

The structure is modeled as a two-dimensional half MBB beam. The classical baseline uses a finite element mesh of \(600 \times 200\) bilinear quadrilateral elements. The MTOP model uses a finite element mesh of \(120 \times 40\) elements and a density mesh of \(5 \times 5\) density cells per finite element, resulting in the same \(600 \times 200\) density resolution as the classical model.

\subsection{Boundary conditions and loading}

The boundary conditions and load are taken from the half MBB beam lecture implementation. The beam is loaded by a vertical point force at the upper-left node of the half model. Symmetry and support constraints are imposed as in the Chapter 9 lecture code.

\subsection{Material interpolation}

The density-based topology optimization uses SIMP interpolation:
\begin{equation}
  E(\rho_e) = E_{\min} + \rho_e^p (E_0 - E_{\min}),
  \label{eq:simp}
\end{equation}
where \(\rho_e\) is the physical element density, \(p = 3\) is the penalization power, \(E_0 = 1\), and \(E_{\min}=10^{-9}\).

\section{Optimization problem}

The minimum-compliance topology optimization problem is formulated as
\begin{align}
  \min_{\mathbf{x}} \quad & C(\mathbf{x}) = \mathbf{F}^{T}\mathbf{U} \\
  \text{subject to} \quad & \mathbf{K}(\mathbf{x})\mathbf{U} = \mathbf{F}, \\
  & \frac{1}{N}\sum_{i=1}^{N} \rho_i \leq V^*, \\
  & 0 \leq x_i \leq 1,
\end{align}
where \(\mathbf{x}\) contains the design variables, \(\rho_i\) are the physical densities, \(V^*=0.5\) is the prescribed volume fraction, and \(N\) is the number of density cells or finite elements depending on the formulation.

\section{Filtering and projection}

\subsection{Sensitivity filtering}

The first study uses sensitivity filtering with a filter radius of \(24\) elements on the \(600 \times 200\) density scale. The filtered sensitivity is computed from neighboring density cells within the filter radius.

\subsection{Density filtering}

The density-filtered formulation first maps design variables to filtered densities and then evaluates the objective, constraint, and sensitivities with respect to the original design variables through the filter operation.

\subsection{Heaviside projection}

For the MMA experiments, Heaviside projection is applied after density filtering:
\begin{equation}
  \bar{\rho}_i =
  \frac{\tanh(\beta\eta) + \tanh(\beta(\tilde{\rho}_i-\eta))}
       {\tanh(\beta\eta) + \tanh(\beta(1-\eta))},
  \label{eq:heaviside}
\end{equation}
where \(\tilde{\rho}_i\) is the filtered density, \(\eta\) is the projection threshold, and \(\beta\) controls projection sharpness.

\section{Solution strategy}

\subsection{Classical OC baseline}

The first benchmark solves the classical MBB problem using the optimality criteria method with:
\begin{itemize}
  \item mesh size \(600 \times 200\),
  \item volume fraction \(0.5\),
  \item penalization power \(3\),
  \item sensitivity filter radius \(24\).
\end{itemize}

The convergence history is recorded both by iteration number and by elapsed wall-clock computation time. The implementation follows the lecture script structure: the physical density is equal to the design density for sensitivity filtering, the compliance sensitivities are filtered, and the OC bisection enforces the volume constraint at each iteration.

\subsection{MTOP with optimality criteria}

The MTOP implementation keeps a fine density representation while solving equilibrium on a coarser analysis mesh. Each \(120 \times 40\) finite element contains \(5 \times 5\) density cells. The stiffness contribution of each analysis element is computed from the density cells assigned to that element.

For an analysis element \(e\), let \(\mathcal{D}_e\) be the set of its \(25\) density cells. The SIMP scaling of the element stiffness is computed as the average of the penalized density values,
\begin{equation}
  \alpha_e = \frac{1}{25}\sum_{i \in \mathcal{D}_e} x_i^p,
\end{equation}
so that
\begin{equation}
  \mathbf{K}_e = \left(E_{\min} + (E_0-E_{\min})\alpha_e\right)\mathbf{K}_0.
\end{equation}
The compliance sensitivity for a density cell \(i\) inside analysis element \(e\) is therefore
\begin{equation}
  \frac{\partial C}{\partial x_i}
  =
  -\frac{p}{25}(E_0-E_{\min})x_i^{p-1}
  \mathbf{u}_e^T\mathbf{K}_0\mathbf{u}_e.
\end{equation}
These sensitivities are then filtered on the full \(600 \times 200\) density grid using the same sensitivity filter radius as in the classical baseline.

\subsection{MTOP with MMA}

The final study replaces the optimality criteria update by MMA. The MMA experiments are performed for sensitivity filtering, density filtering, and Heaviside projection with several projection thresholds.

\section{Results}

\subsection{Classical OC baseline}

The classical OC baseline for assignment step 1 converged after \(94\) iterations. The final compliance was \(224.5961\), the final volume fraction was \(0.500074\), and the final maximum design change was \(9.95 \times 10^{-3}\). The measured wall-clock time on the machine used for this run was \(\SI{241.99}{\second}\).

\section{Discussion}

The step 1 design shows the expected half MBB beam load paths: material is concentrated in the main chord regions and in diagonal members that transfer the applied load toward the support. The relatively large sensitivity filter radius produces smooth, wide members and suppresses checkerboard patterns. The volume history confirms that the OC update keeps the design close to the prescribed volume fraction, while the compliance history shows a rapid early decrease followed by a slow approach to the final layout.

The MTOP result preserves the same main load paths as the classical solution. The mean absolute density difference is \(0.00217\), the RMS density difference is \(0.00429\), and the maximum absolute density difference is \(0.03035\). This indicates that, for sensitivity filtering with a radius of \(24\) density cells, the coarse \(120 \times 40\) analysis mesh does not visibly change the final density layout. The fine-mesh compliance evaluation confirms this visual comparison: the MTOP design is only \(0.0357\%\) higher in compliance than the classical design when both are evaluated on the \(600 \times 200\) finite element mesh.

The iteration counts are almost identical, with \(94\) iterations for the classical baseline and \(93\) iterations for the MTOP run. The main difference is computational cost. The MTOP optimization took \(\SI{8.82}{\second}\), compared with \(\SI{241.99}{\second}\) for the classical baseline, giving a wall-clock speedup factor of \(27.43\) for this run. This speedup comes from solving the equilibrium equations on the coarse analysis mesh while keeping the same density resolution for the design description.

The remaining discussion will compare these sensitivity-filtered OC results with the alternative filtering and optimizer choices. Important points to address include:
\begin{itemize}
  \item how sensitivity filtering and density filtering affect the comparison,
  \item how MMA and Heaviside projection influence discreteness, convergence, and computational cost.
\end{itemize}

\section{Conclusion}

Assignment step 1 established the classical OC reference solution for the \(600 \times 200\) MBB beam with sensitivity filtering. Assignment step 2 shows that the MTOP formulation with a \(120 \times 40\) finite element mesh and \(5 \times 5\) density cells per finite element reproduces nearly the same density layout while reducing the measured optimization time by a factor of \(27.43\). The final MTOP design remains essentially equivalent to the classical design when it is evaluated on the fine finite element mesh.
